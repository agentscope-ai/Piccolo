# 面向小模型的意图输入

本文中的 `${RUN_DATA}` 表示评测产物的父目录，按当前机器的挂载位置设置。

模型需要判断“现在追哪个目标、选哪个意图、收益和代价是什么、执行后还能否继续”，不需要逐帧重建执行器。此次修改只调整公开观测到模型请求的投影，物理、动作 ID、候选集合、计分、原生胜负、对手与决策预算不变。

## 首轮结果与最终默认

首轮 `intent-v2` 在 12 款游戏的 41 个配对对局中，成功数 **21→18**；并未提高总体成功率。马里奥 1/3→0/3、6×6 黑白棋 4/4→3/4、Hex 3/4→1/4，国际象棋 0/3→1/3，其余游戏胜数持平。全部原始结果保留，不补跑替换失败。

因此默认入口改为固定的 `selected-v1` 表示配置：

| 游戏 | 最终表示 | 选择依据 |
|---|---|---|
| 五子棋、泰拉瑞亚 | intent-v2 | 输入与耗时下降，配对胜数持平；未证明通关能力提高 |
| 马里奥 | lossless-v1 | 另跑相同 3 个种子得到 2/3 通关；保留原策略指导及全部预测，只去重并缩短动作描述 |
| 6×6 黑白棋、Hex | original | 首轮胜数下降，保守恢复完整原表示 |
| 其余首轮有收益的 7 款游戏 | lossless-v1 | 无损结构去重；国际象棋胜数增加，其余胜数持平 |
| 其余 16 款游戏 | original | 无足够压缩收益或预测主要在动作描述中，保持原样 |

最终实际优化 10 款、保持原输入 18 款。`selected-v1` 只选择表示方式，不读取评测结果动态切换，不代替模型选动作。CLI 可显式请求各实验格式。马里奥补测是同种子的表示消融；每款只有 3–4 局，并非独立留出验证。不能把回退后复用的旧结果拼成一轮全新评测，或据此宣称统计显著提升。

## 保留和压缩的边界

| 信息 | 处理 | 决策用途 |
|---|---|---|
| 胜利条件、阶段目标、必要前置条件 | 保留并集中到 goal/rules | 避免用金币、挖矿或靠近门代替通关 |
| 当前位置、支撑、可见地图、敌人、资源和装备 | 保留公开事实与精度 | 判断可行性、威胁与资源代价 |
| 每个动作的落点、收益、失败、风险、完成条件 | 按意图归并 | 直接比较候选，不跨长段文字找结论 |
| 推理等待期间的风险、动作后的可达区 | 保留原预测值与不确定性 | 避免动作本身安全、等下一次响应时死亡 |
| 最近实际效果、失败目标、拒绝原因 | 保留 | 避免重复无效动作，区分失败和执行到期 |
| 每个候选重复的规则、来源和说明 | 提取公共说明或去重 | 减少干扰与输入长度 |
| 走位路径、剑框矩形、可从坐标恢复的格索引、审计版本 | 留在完整观测和回放 | 模型读取执行器已算好的可达性/命中/风险结果 |

未知、缺失和 false 不合并；历史位置不当作当前可见位置；预测不是成功概率或安全保证。没有把具体目标的选择交给额外规则策略，也没有偷偷增加观察范围。

## 三款重点游戏

- **五子棋**：保留完整棋盘、阵营、规则、对手立即胜点和每个候选的本步获胜、对方下一步获胜坐标、己方连续子数。删除每个落点反复出现的同义长解释、来源与可从动作坐标推导的行列。候选只写“落子 x,y”。不删候选，不根据胜率筛选。
- **马里奥**：最终版保留原规则、完整策略指导和全部结构化公开事实，使用无损表格及同值引用去重。动作改为“向右跳”“指定障碍越过一次”“原地等待安全窗口”等意图。每项集中展示落点、支撑、撞头、碰敌/花、掉坑、未知区域、落点花口暴露、1 秒等待/松键风险、4/8 秒延迟情景、敌人接触时间、后续一次跳跃的前进区和退路。保留显式落地防御授权及期限。最终版连原始花高度历史也继续提供，保留可行相位数、风险及其不确定性；没有把预测压成安全保证。首轮更激进的重写版本留作实验复现。
- **泰拉瑞亚**：围绕“成长→接近守卫→真实命中并持续战斗→解锁后进门”组织输入。保留敌我伤害、所需命中次数、可承伤次数、实际射程/方向、失败反馈、采集绑定目标与装备收益、升级成本和缺口、历史目标时龄。去掉四向剑框矩形与逐帧执行细节，保留其几何计算结果及不确定性。实际玩家参与击杀和原生 wins 条件不变。

其他 25 款游戏也已扫描。黑白棋两种尺寸、Hex、点格棋、2048、推箱子、地产、国际象棋和 Pig 共 9 款在首轮试用了无损表格/公共字段去重；仅在该条请求整体至少缩短 10% 时应用。其余 16 款本次保持原输入，包括预测主要写在动作标签中的贪吃蛇、俄罗斯方块和赛车。

五子棋、泰拉瑞亚及首轮马里奥试验使用 `jev.model-input.intent.v2`；最终马里奥和其他保留的结构去重使用 `jev.model-input.compact.v1`。前者有意省去执行细节，不能声称全部原始字段可无损恢复；后者可还原全部结构化公开字段。

## 引擎与前端同源

`EngineSpec.model_input(state)` 调用 `project_record(engine.observe(state), "selected-v1")`。网页会话、旧试玩接口、棋盘及世界观测接口均用这一投影；网页模型评测也在调用模型前投影。完整 `observe()`、底层 runner 和历史回放保持原合同。

棋盘接口返回 `previous_input`，输入面板展示本步真正发给模型的快照，避免把落子后的下一步输入显示成本次请求。两种宽度的浏览器回归会比较主三款游戏的实际请求与输入面板。

非游戏问题、未纳入此次优化的游戏直接透传。独立评测脚本默认 `--input-format original`，复现旧结果不受网页默认投影影响；首轮对照显式指定 `intent-v2`，马里奥消融使用 `lossless-v1`，复现最终默认配置可指定 `selected-v1`。

## 对照口径

原 30000 评测已按用户要求中断：计划 224 局，完成 89 局。封存这 89 局及 6292 次请求，未形成终局的两局不计为失败，不纳入配对。每款原本完成 3 或 4 局，成功率分母按实际完整对局计算。

此次有输入变化的 12 款游戏共 **41 个配对对局**。复用原计划的游戏、精确种子、席位、对手、预算、每步探测次数；全局模型 HTTP 并发为 2。回合游戏每决策仍做 3 次选项顺序探测，实时游戏 1 次；唯一合法动作不请求模型。

另从每款已完成对局中选短/中/长各一个实际公开快照，原版与新版交替 AB/BA 请求，测量服务返回的 input_tokens 和 HTTP 总耗时。动作一致不等于任务成功。整局耗时包含物理运行和多次模型决策；HTTP 含上游排队，不等于纯 GPU 推理时间。

基线与冻结评测源码、预测核对、逐次请求、错误、重试、逐局终局及动态报告保存在：

```text

  source/                    # 本轮评测冻结源码
  prediction-audit.json
  comparison/same-input/     # 同一公开快照的真实请求统计
  comparison/episodes-run/   # 相同种子的完整引擎 rollout

  comparison/comparison.json
  mario-lossless-run/         # 相同3个Mario种子的保守压缩消融
  mario-lossless-probe/       # 保守版与原版的同输入token/耗时

```

运行入口：

```bash
python scripts/compare_model_inputs.py \
  --baseline <封存基线目录> --out <独立对照目录> \
  --completed-baseline-only \
  --games gomoku_19x19 mario_platformer terraria_survival \
    othello_6x6 othello_8x8 hex_7x7 dots_and_boxes_3x3 \
    merge_2048 sokoban_puzzle property_tycoon chess pig_dice
```

不得把运行中的未完成局当失败，也不得只挑成功种子。每款 3–4 局只适合检查趋势，不能据此宣称统计显著提升；实时游戏轨迹还会随实际响应时间变化。

首轮发布前验证：223 项 Python 测试（含真实 HTTP 会话）、23 项 Node 测试通过；6292 条封存请求的发布候选投影与冻结评测源码输出完全相同。兼容性修正只保证非游戏问题透传、原始评测入口不受前端默认投影影响，以及错误统计完整，不改变本轮实际发送输入。

最终默认选择再次通过 **225 项 Python 测试**；新增对马里奥、6×6 黑白棋、Hex 的桌面/手机 **6 项浏览器回归**全部通过。6292 条封存请求确认最终默认输出与实际测过的相应格式完全相同。马里奥保守版同输入均值为 **13100→7926 tokens、4.02→2.38 秒**，3 个种子的通关为 **1/3→2/3**；没有把这组小样本选型当成独立泛化验证。
