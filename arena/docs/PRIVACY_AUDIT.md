# 隐私与脱敏审计

本次审计只记录规则、分类、统计和处理结果，不保存命中的敏感值。未连接真实模型、重跑评测、删除源数据或改变已发布成绩。

## 公开成绩与回放

发布成绩现统一位于 `leaderboard/`，包含三个 benchmark、Arena 快照与独立回放，共 5 个 JSON 文件。迁移逐字节保留数据；三个 benchmark 各 8 个模型，Arena 为 3 模型、21 游戏、99 个已计分比较。99 场回放与 27 条 episode 的轮次、赛程身份、结算结果和引用一致性已经检查。

递归检查 JSON 解码后的键和值，所有公开成绩中 `served_model`、`model_path`、`tokenizer_path`、`source_url`、`source_path`、`username`、密钥和凭据字段数量均为 **0**。模型保留公开 ID、显示名以及必要的 provider/policy 标识，未导出内部 checkpoint 精确位置。回放保留游戏公开状态和执行动作，不保存模型请求报文、推理文本或隐藏系统提示。

榜单 JavaScript 中两份包含机器绑定信息的历史 fallback 已移除。公开导出采用嵌套字段白名单，再拒绝绝对路径、存储 URI、地址字面量、内部主机名、凭据特征及私有字段。导出错误只报告异常类别，不输出请求地址、响应正文或命中的值。导入 CLI 只报告目标文件名，不回显部署机器的绝对目录。

## 前后端模型连接

当前连接合同只接受 `browser` 模式。模型服务地址和密钥由浏览器内存中的连接桥持有，浏览器直接调用用户填写的服务；后端不接收 endpoint/key，也不执行模型 HTTP 转发。旧 `proxy` 模式及 endpoint、API key、环境变量凭据字段由后端合同拒绝。

运行时后端只登记该浏览器拥有的模型身份和调度状态，用于严格核验响应模型及合法动作。注册身份与公开榜单分离；公开评测投影过滤服务定位和私有执行字段。浏览器模型地址、密钥不写 localStorage/sessionStorage，不进入成绩或回放文件。错误通过有限错误码返回，避免把远端请求报文带入 UI。

会话、连接与实时控制按浏览器 cookie 隔离。已验证创建响应启用 gzip 时仍正确登记所有者，跨 cookie 的原生会话、通用 tick/cancel 请求均拒绝访问。模型连接隔离、失效、取消和响应校验由独立连接测试覆盖。

## 清理与最终扫描

初次发现并清理的内容包括：2 处配置中的机器绝对路径、2 处旧部署 proxy 链接、旧本地连接示例以及前端数据审计入口。内部模型路径、机器目录拥有者标识、旧线程定位、外部源码导入与模型服务预配置均按发布范围检查。旧隐藏 catalog/schema 容器不再依赖训练数据；试玩使用公开游戏合同与空 catalog。

最终对 `web/`、`config/`、`leaderboard/` 的 45 个文本文件进行原文及转义解码扫描，结果如下：

| 规则 | 未处理命中数 |
| --- | ---: |
| 本机绝对工作路径 | 0 |
| 旧部署 proxy 域名 | 0 |
| CPFS/OSS 内部定位 | 0 |
| provider 凭据值特征 | 0 |
| Codex 线程标识 | 0 |
| 非公开个人/机器标识 | 0 |

宽泛的名称匹配在 `web/credits.html` 命中 7 处，全部属于刻意保留的公开作者/仓库归属信息。用户明确要求提供复用或参考仓库的来源链接，因此这些公开出处不作为私有标识删除；没有把它们带入成绩数据或模型连接配置。字体及其他第三方许可证同样保留。

最终整包集成扫描检查了 141 个发布文件，私有工作目录、旧域名、线程 ID、凭据特征和外部 `src.tools` 依赖均为 0。统计针对发布内容，临时测试数据、浏览器截图、运行目录及本地环境不随仓库分发。
