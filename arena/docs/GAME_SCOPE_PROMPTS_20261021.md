## 决策信息与候选 prompt

默认继续采用已选定的 `selected-v1`：Othello 6×6、Hex 保留原输入；Mario 保留全部结构化预测及原指导，压缩重复字段；Terra 使用意图视图，保留公开资源、战斗、路径风险和通关条件。原始 `engine.observe()` 仍用于回放；`engine.model_input()` 提供网页实际决策视图。

`config/game-prompts.candidate.json` 是实验配置，默认不启用。它调整斗地主、德扑、炸金花、扫雷、UNO、跳棋和象棋的行动指导，不修改观测事实、候选动作 ID、顺序、成功条件或对手。`JEV_GAME_PROMPTS_PATH` 选择配置；冻结 RL bundle 在导入模块前设置 `JEV_GAME_SCOPE_PATH` 绑定打包的范围文件，避免依赖开发目录；RL 绑定配置时使用同一个 `jev_game_prompt_calibration.config_path()`。

对照入口 `scripts/evaluate_systemone.py` 支持 `--prompt-config`、`--expected-model-path` 和 `--baseline-plan`。每次运行冻结实际配置，核对服务和实际推理后端的 checkpoint、direct 模式、双向 prompt 注意力；后测复用前测种子，并拒绝不同模型或并发的比较。错误与预算耗尽留在计划分母中。

训练调用方必须把最终决策视图的渲染、token、候选映射同时接入 rollout 和 learner，不能只压缩推理端、仍训练旧原始输入，也不能再叠加另一套未经验证的压缩。原始观测/回放与实际模型输入应分别保存并进行逐条一致性验证。

## 资料与验证

参考 [GamingAgent 的原始 prompt](https://github.com/lmgame-org/GamingAgent/tree/main/gamingagent/configs) 中的短目标、历史动作效果和公开局面描述；只采用适用的策略信息，不照搬其动作、坐标、图像编码和长推理输出格式。[RAPOA](https://arxiv.org/abs/2606.17838) 使用环境回报验证针对性 prompt 修改；这支持本轮采用真实对局对照的验证方法，不代表本模型已经获得相同收益。

本轮范围及接口回归：212 项 Python 检查通过；22 项需要 live URL 的检查另行运行，HTTP 会话检查合计 29 项通过；32 项 Node 检查通过。22 款游戏在 1440 和 390 宽度下共 44 项浏览器检查通过，覆盖换种子、报错恢复、连玩停止、终局重置、私有手牌交接和输入显示，无页面异常。实时游戏另通过 14 项重力、死亡恢复、旧请求隔离检查；新增反馈显示通过桌面/手机与中英文共 4 项检查。这些浏览器检查使用 fixture 模型，不是模型成功率。

本轮已完成原对照 112 局及扫雷修复后的补测 16 局。七组新增策略提示均未采用，默认保留原提示。详见[逐游戏结果](PROMPT_PILOT_RESULTS_20261021.md)；八种子试验不作为泛化提升证明。

## 原生重试反馈

实测扫雷在第一次踩雷后会按 TextArena 原生规则保留一次重试机会，并向玩家报告雷格；旧适配层只传盘面，遗漏该反馈，因此模型可能重复点雷。数独也有同类错误反馈缺失。修复只保留原生已经公开的失败动作及原因、剩余连续重试次数，前端以统一提示区域显示；不查询隐藏雷图或标准答案，也不改变候选动作、奖励及失败规则。

该修复的公开视图标记为 `selected-feedback-v2`，动作日志版本保持不变。原 A/B 中的扫雷结果保留供排障；策略提示的最终选择采用相同修复引擎、相同种子的独立 8+8 局。其他游戏的原 A/B 保持不变。
