# Playground 游戏分类

选择器使用两个原生下拉框，先选择分类，再选择具体游戏。切换分类只筛选候选；选择具体游戏后才切换世界。游戏列表、浏览目录和 Piccolo Arena 雷达图共享 `web/playground/game-categories.js`。

| 分类 | 游戏 | 数量 |
| --- | --- | ---: |
| 概率 | 二十一点、德州扑克、吹牛骰子、炸金花、斗地主、UNO、猜数字、扫雷 | 8 |
| 策略 | 黑白棋 6×6、六角棋、点格棋、国际象棋、西洋跳棋、中国象棋 | 6 |
| 长程 | 2048、推箱子、地产大亨、数独 | 4 |
| 实时 | 泰拉瑞亚、俄罗斯方块、贪吃蛇、马里奥 | 4 |

按主要决策特点归类：概率组强调不确定信息，策略组为棋盘对抗，长程组强调多步推进，实时组在模型响应期间继续计时。每款游戏只出现一次。

雷达保留全部 22 个游戏维度，按上述分类放入四个象限，分类名位于图外四角，不绘制包围圆弧。每个游戏的轴值、Elo、计分顺序和综合游戏权重保持原有计算；分类不产生额外的聚合分数。

左侧游戏图标来自随站点分发的 Noto Emoji 子集字体，许可证保存在 `web/playground/fonts/NotoGameEmoji-LICENSE.txt`。
