# Model logos

These assets identify models on the leaderboard. Piccolo uses the official AgentScope AS logo with its original blue-to-purple gradient.

`agentscope.svg` is the original official asset. `blink.svg`, `blink-light.svg` and `blink-favicon.svg` are identical compatibility copies for existing URLs. `blink-wordmark.svg` combines the AgentScope mark with the Piccolo wordmark. `oneshot.svg` remains available for historical recordings.

Sources: [AgentScope README](https://github.com/agentscope-ai/agentscope/blob/main/README.md) · [Original SVG](https://img.alicdn.com/imgextra/i1/O1CN01nTg6w21NqT5qFKH1u_!!6000000001621-55-tps-550-550.svg).

All icons are bundled locally. Models without a verified brand match receive no automatic icon.

StartLux, Strands, Cloudflare, OpenAI, vLLM Semantic Router and Perplexity use their official icons. See [publisher sources](PUBLISHER_SOURCES.md) and the mapping in `../model-logo.js`. Strands and vLLM-SR use their publishing team's marks; Qwen models use the Qwen icon and link to [Qwen](https://qwen.ai/).
