# Piccolo 开头备选

## 版本一：参考 Atria，侧重应用与体验

参考：[Atria Dawn](https://atria-asi.ai/)

今天，我们发布 **Piccolo**，一个强大、快速、高性价比的决策模型，让智能判断走进更多应用。从游戏中的连续行动，到智能体的工具审核与上下文筛选，Piccolo 理解当前状态、比较候选项，返回程序可以直接使用的结果与概率。

我们通过完整的交互展示、评测结果和 QwenPaw 本地接入，呈现 Piccolo 的能力与实际用法。你可以观看它如何完成一局游戏，也可以将它接入自己的工作流。欢迎开发者与研究者带来新的场景，一起探索决策模型还能做什么。

## 版本二：参考 Baseten，侧重定位与结果

参考：[Mammoth-1 and Elephant-1: frontier decision models](https://labs.baseten.co/articles/mammoth-1-and-elephant-1-frontier-decision-models)

今天，我们发布 **Piccolo**，为高频判断而设计的决策模型。Piccolo 27B 在 JevBench 上取得 **92.21%** 的准确率，在 Decision Index 上取得 **68.29** 分。

工具能否执行、下一步如何行动、哪些上下文值得保留——这类任务需要理解复杂背景，最终输出却往往只是一个选择。Piccolo 直接计算候选项的概率，返回结构化决策，供程序依据规则与阈值组织后续执行。

从游戏中的连续决策，到 QwenPaw 中的本地工具审核与上下文筛选，我们进一步展示 Piccolo 如何进入实际工作流，让模型的判断成为软件可以调用的能力。
